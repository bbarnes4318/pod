### Design rules (full detail in `docs/studio-design.md`)

- **One accent per screen.** `--accent` is primary/live/Generate only.
- Signature element is the **rundown rail** — tally lights, monospace timecodes.
  Spend the boldness there, keep everything else quiet.
- Motion 120ms state / 200ms reveal / 320ms max. Honour `prefers-reduced-motion`.
- Progressive disclosure: use the existing `.advPanel` / `.advLink` /
  `.studioNoteDisclosure`, do not invent a parallel pattern.
- Spacing: only 4/8/12/16/24/32/48. No card over 32px vertical padding.
- **`--error` is for fills/borders; `--error-text` is for small text.** Not
  interchangeable — `--error` fails AA as body text.
- Copy: sentence case; buttons are verbs and the verb survives ("Publish" →
  "Published"); user vocabulary not system vocabulary; no decorative emoji in
  section headings; **never use the word "booked"**; no "Oops!", no exclamation
  marks, no apologising errors.
